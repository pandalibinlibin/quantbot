全球数字货币列表

接口：coinlist
描述：获取全球数字货币基本信息，包括发行日期、规模、所基于的公链和算法等。

输入参数

名称 类型 必选 描述
issue_date str Y 发行日期
start_date str N 开始日期
end_date str N 结束日期

输出参数

名称 类型 描述
coin str 货币代码
en_name str 英文名称
cn_name str 中文名称
issue_date str 发行日期
issue_price float 发行价格（美元）
amount float 发行总量
supply float 流通总量
algo str 算法原理
area str 发行地区
desc str 描述
labels str 标签分类

接口用法


pro = ts.pro_api()

df = pro.coinlist(start_date='20170101', end_date='20171231')

或者


df = pro.query('coinlist', start_date='20170101', end_date='20171231')
