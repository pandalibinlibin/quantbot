## 第一步：前置知识雷达（Prerequisite Radar）

本节内容（页13-15）主要涉及基础金融概念，无需复杂数学前置，但需建立以下直觉：

### 基础补丁

**1. 生活实例补丁：什么是「借钱」的本质？**  
想象菜市场：张三种了100斤白菜但想换大米，李四有大米但想换白菜。直接交换是**易货贸易**。但如果张三想要大米现在就给，但白菜下个月才收，李四说「可以，但下个月你要还我110斤白菜」——这多出的10斤就是**利息（Interest）**，而张三写的欠条就是**债券（Bond）**。金融市场就是把这个欠条标准化、可交易的场所。

**2. 术语补丁（本节核心名词）**：  
- **证券（Security）**：对未来收入的索取权证明，通俗说就是「欠条的标准化版本」。  
- **债券（Bond）**：承诺定期支付的债务证券，有到期日和票面利率。  
- **利率（Interest Rate）**：借款成本，表示为借入100元每年支付的利息比例（如5%即每年付5元利息）。  
- **普通股/股票（Common Stock/Equity）**：公司所有权的份额凭证，持有者享有剩余索取权（公司先还债，剩下的才分红给股东）。  
- **资产（Asset）**：具有经济价值、能持有以获取收益的东西（现金、债券、股票、房产都是资产）。  
- **金融市场（Financial Market）**：资金从盈余方（储蓄者）流向短缺方（借款者）的场所。

**3. 编程补丁**：本节暂不涉及代码，但为后续量化铺垫，理解「时间序列」概念——即按时间顺序排列的数据点（如每月CPI数据），类似Excel中按日期排序的A列。

### 1. 概念直觉层（生活案例→金融市场）

**案例1：菜市场的「时间价值」（理解利率）**  
你去菜市场买白菜，今天买是2元/斤。摊主说「如果你现在付定金，我一个月后给你，还是2元/斤」。你不愿意——因为一个月后可能白菜涨到2.5元，或者你现在2元买可以存银行赚利息。**利率就是「现在拥有钱」vs「未来才收到钱」之间的补偿价格**。如果银行年利率5%，意味着今天的100元=明年的105元。

**案例2：奶茶店的扩张（理解股票）**  
你开的奶茶店很火，想再开10家分店需要100万。你有两个选择：
- **借债（债券逻辑）**：向银行借100万，承诺3年后还110万（利息10万）。无论店赚多少，银行只拿固定利息。
- **合伙（股票逻辑）**：找5个朋友每人投20万，占股20%。店赚了分20%利润，亏了共担风险。这就是**剩余索取权**——债权人（银行）先拿，股东后拿。

**案例3：真实的金融市场波动（书中页3-4数据）**  
书中图1-1显示：1981年3个月期国库券利率峰值**超过16%**（借100元每年还16元利息），1992年跌至**3%**，2004年**1%以下**，2017年回到**1%以上**。这种巨大波动直接影响：
- 你的房贷利率（16%时月供 vs 3%时月供差异巨大）
- 企业建厂成本（高利率时推迟投资，减少就业）

### 2. 宏观指标六维拆解（本节核心：利率）

本节涉及关键指标**利率（Interest Rate）**，强制执行六维拆解：

**(1) 定义与计算**  
- **官方定义**：利率是借款的成本或为借入资金支付的价格，通常表示为借入100美元每年支付的利息在100美元中所占的比例。  
- **公式**：  
  $$r = \frac{\text{利息支付}}{\text{本金}} \times 100\%$$  
- **手算示例**：  
  假设你购买面值100元的1年期国债（国库券），发行价96元，到期收回100元。  
  利息 = 100 - 96 = 4元  
  利率 $r = \frac{4}{96} \times 100\% \approx 4.17\%$（书中称为贴现收益率）

**(2) 经济学含义**  
- **名义利率（Nominal Interest Rate）**：未调整通货膨胀的利率（如房贷利率4%）。  
- **实际利率（Real Interest Rate）**：名义利率减去通货膨胀率（如通胀2%，则实际利率≈2%）。实际利率才是真实的资金成本。  
- **升降含义**：利率上升→融资成本增加→企业推迟投资→失业率可能上升；利率下降→刺激消费和投资→经济扩张。

**(3) 日常生活映射**  
- **房贷月供**：假设贷款100万元，30年等额本息。
  - 利率3%：月供约4,216元，总利息约51.8万元
  - 利率6%：月供约5,996元，总利息约115.8万元  
  **手算差异**：利率从3%→6%，月供增加$\frac{5996-4216}{4216} \approx 42.2\%$，总利息翻倍。
  
- **储蓄收益**：10万元存银行，年利率2%→年利息2,000元；若降至0.5%→年利息仅500元。

**(4) 传导路径**  
绘制完整传导链：
$$\text{央行政策利率} \rightarrow \text{银行间利率（联邦基金利率）} \rightarrow \text{房贷利率/企业贷款利率} \rightarrow \text{购房成本/投资成本} \rightarrow \text{消费/投资决策} \rightarrow \text{GDP增长/失业率}$$

**(5) 数据获取指南（聚宽为主，Wind备选）**  
- **聚宽（主要）**：
  - 路径：joinquant.com → 「研究」→ 「数据研究」→ 「宏观数据」→ 「利率数据」

  - API代码示例：`M0014279`（3个月国债收益率）

**(6) 量化监控框架**  
- **发布频率**：日度（银行间市场）、月度（存贷款基准利率）  
- **滞后性**：T+1公布  
- **数据修正**：较少修正，但历史数据会回溯调整（如季节性调整）  
- **市场预期差（Surprise）计算**：  
  $$\text{Surprise}_t = \text{Actual}_t - \text{Consensus}_t$$  
  例如：市场预期利率维持3%，实际加息至3.25%，则Surprise=+25bp（基点）。  
- **历史敏感性**：利率Surprise +10bp 通常导致：
  - 债券价格：下跌约0.5%（久期5年的债券）
  - 股市：短期承压（资金成本上升）
  - 汇率：本币升值（利差扩大）

### 3. 数学结构层（手算强制）

**债券定价基础（为本节利率讨论奠基）**  
书中提到利率影响债券价格，虽未详述公式，但需理解基础：

**符号解码**：
- $P$：债券价格（ scalar标量，单位：元）
- $C$：票面利息（Coupon，每期固定支付，如每年5元）
- $r$：市场利率（Yield to Maturity，到期收益率）
- $T$：剩余期限（年）
- $F$：面值（Face Value，到期归还的本金，通常100元）

**债券价格公式**：
$$P = \sum_{t=1}^{T} \frac{C}{(1+r)^t} + \frac{F}{(1+r)^T}$$

**手算示例（2年期债券）**：  
假设债券面值$F=100$元，每年付息$C=5$元（票面利率5%），市场利率$r=4\%$。

- **第1年现金流现值**：$\frac{5}{(1+0.04)^1} = \frac{5}{1.04} \approx 4.8077$元  
- **第2年现金流现值**：$\frac{5}{(1+0.04)^2} + \frac{100}{(1+0.04)^2} = \frac{105}{1.0816} \approx 97.0762$元  
- **债券价格**：$P = 4.8077 + 97.0762 \approx 101.88$元（溢价，因为票面利率>市场利率）

**反向验证（利率上升至6%）**：  
- 第1年：$\frac{5}{1.06} \approx 4.7170$元  
- 第2年：$\frac{105}{1.1236} \approx 93.4480$元  
- 新价格：$P \approx 98.17$元  
- **价格下跌**：$\frac{101.88-98.17}{101.88} \approx 3.64\%$（利率升2%，价格跌3.64%）

**经济含义**：利率与债券价格反向变动。书中1981年利率16%时，长期债券价格极低；1992年利率3%时，债券价格高涨。

## 第四步：量化投资映射（Quantitative Investment Mapping）

### 4.0 设计哲学（强制解释）

**问题1：什么是因子？**  
本节「利率水平」可构建为**宏观趋势因子**。它预测资产价格的逻辑是：利率变动→折现率变化→资产重估。需满足：
- **预测力**：历史数据显示利率与股市估值（PE）负相关（$r \uparrow \Rightarrow PE \downarrow$）。
- **可交易性**：可通过国债期货、债券ETF、利率互换交易。
- **逻辑自洽**：资金成本上升压制风险资产价格。

**问题2：宏观→交易如何传导？**  
以「奶茶店原料涨价」类比：
- 宏观状态：面粉（原料）涨价 → 奶茶店成本上升 → 利润下降 → 股价下跌。
- 金融市场：利率（资金成本）上升 → 企业融资成本增加 + 股票折现率上升 → 双杀股价。

**问题3：为何需数学处理？**  
利率数据噪音小但趋势性强，需：
- 去噪：移动平均识别趋势（而非单日波动）。
- 预期差：市场定价的是「预期内的加息」，只有「超预期」才产生交易信号（Surprise）。
- 标准化：将利率变动转为Z-Score，比较不同时期的冲击强度。

```python
df_rate['MA5'] = df_rate['value'].rolling(window=5, min_periods=1).mean()
df_rate['MA20'] = df_rate['value'].rolling(window=20, min_periods=1).mean()

# 生成趋势信号：短期>长期为上升趋势（利率上行）
# np.where 类似Excel的IF函数
import numpy as np
df_rate['signal'] = np.where(df_rate['MA5'] > df_rate['MA20'], 1, -1)  
# 1表示利率上行趋势（利空债券），-1表示下行趋势（利好债券）

print("信号分布：")
print(df_rate['signal'].value_counts())
```

```python
# 按月对齐数据（宏观数据是日度，但逻辑按月调仓）
df_rate['month'] = pd.to_datetime(df_rate['date']).dt.to_period('M')
df_bond['month'] = pd.to_datetime(df_bond.index).dt.to_period('M')

# 合并数据
merged = pd.merge(df_rate[['month','signal']], df_bond[['close']].resample('M').last(), 
                  left_on='month', right_index=True)

# 计算下期收益（信号生成后持有1月）
merged['return'] = merged['close'].pct_change().shift(-1)

# 统计：利率上行信号（-1）时，债券平均收益是多少？
avg_return_up = merged[merged['signal']==-1]['return'].mean()
avg_return_down = merged[merged['signal']==1]['return'].mean()

print(f"利率上行趋势时，债券月均收益：{avg_return_up:.2%}")
print(f"利率下行趋势时，债券月均收益：{avg_return_down:.2%}")
# 预期：上行时收益为负（价格下跌），下行时收益为正
```

**类型B：周期定位型（美林时钟简化版）**  
**设计逻辑**：结合经济增长（GDP）和通胀（CPI）定位经济周期。本节利率数据是周期定位的输入之一。  
**传导链条**：复苏期（低利率+高增长）→超配股票；滞胀期（高利率+低增长）→超配现金。

**类型C：事件驱动型（利率Surprise）**  
**设计逻辑**：央行利率决策发布时的瞬时冲击。  
**传导链条**：利率决议公布→Surprise计算→若超预期加息→立即做空债券（分钟级交易，见4.5高频层）。

### 4.4 风险控制层

**止损逻辑**：最大回撤15%强制清仓。
```python
# 计算累计净值
cumulative = (1 + merged['return'].fillna(0)).cumprod()
rolling_max = cumulative.expanding().max()
drawdown = (cumulative - rolling_max) / rolling_max

# 触发止损
if drawdown.iloc[-1] < -0.15:
    print("触发15%回撤止损，建议清仓")
```

**波动率自适应**：目标波动率10%。
```python
# 计算20日波动率（年化）
vol = merged['return'].rolling(20).std() * np.sqrt(252)
vol_scalar = 0.10 / vol  # 目标/当前
vol_scalar = vol_scalar.clip(0.3, 1.5)  # 限制0.3-1.5倍

# 调整仓位
position = 0.5 * vol_scalar.iloc[-1]  # 基础仓位50%，根据波动调整
print(f"波动率调整后的仓位：{position:.1%}")
```

### 4.5 高频应用层（如涉及）

本节为月度宏观数据，但利率发布日（如每月20日9:30 SHIBOR发布）可应用高频策略：

**滑点成本手算**：  
假设国债ETF当前：买一价108.50元（量5手），买二价108.49元（量10手）。  
你要市价买入10手（1000份）：
- 先吃掉买一5手：5×100×108.50 = 54,250元
- 再吃买二5手：5×100×108.49 = 54,245元  
- 平均成本：(54,250+54,245)/1000 = **108.495元**  
- 滑点成本：(108.495-108.50)×1000 = **-5元**（负滑点，对你有利，因为是买方市场，但通常卖一价更高，实际成本会增加）

### 4.6 策略验证层

**回测逻辑**：避免未来数据泄露（Look-Ahead Bias）。  
- 错误做法：用当月利率数据生成信号，交易当月债券（因为利率数据可能月末才发布，无法月初交易）。
- 正确做法：用上月末发布的利率数据，生成下月交易信号（滞后一期）。

**聚宽回测设置**：
- **时间范围**：2018-01-01 至 2024-01-01（覆盖疫情周期）
- **初始资金**：100,000元
- **基准**：中证全债指数（或国债ETF本身）
- **关键指标**：夏普比率（Sharpe Ratio，风险调整后收益）、最大回撤（Max Drawdown）、胜率（Win Rate）
