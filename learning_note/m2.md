# 第一步：前置知识雷达（Prerequisite Radar）

本节是全书导论中关于金融机构功能的定性描述，但隐含了三个经济学核心前提：**信息不对称（Asymmetric Information）**、**交易成本（Transaction Costs）** 与 **金融摩擦（Financial Frictions）**。

## 基础补丁

**生活实例补丁**：想象你有一笔闲钱想借给别人买房，但你不认识借款人，不知道他会不会还钱，也不会写合同、做抵押登记。这时房产中介/银行出现了——它们帮你筛选借款人、评估信用、处理法律文件，收取一点手续费。这就是金融中介（Financial Intermediary）的日常版。

**经济补丁**：金融中介存在的根本原因是现实中存在**逆向选择（Adverse Selection，事前信息不对称）** 和 **道德风险（Moral Hazard，事后信息不对称）**。如果没有中介，资金 surplus 方（储蓄者）与 deficit 方（借款人）很难直接匹配，经济效率会大幅下降。

**数学补丁**：本节虽无复杂公式，但涉及基础比率思维。例如，失业率（Unemployment Rate）$u$ 是标量（Scalar，单个实数），定义为失业人口 $U$ 与劳动力人口 $L$ 之比：$u = \frac{U}{L} \times 100\%$。若某城市劳动力人口 $L=500,000$ 人，失业人口 $U=25,000$ 人，则手算过程为：$u = \frac{25,000}{500,000} \times 100\% = 0.05 \times 100\% = 5\%$。

**术语补丁**（本节核心词汇，首次出现附英文）：
- **金融机构（Financial Institutions）**：从事金融业务的组织，包括银行、保险公司、证券公司等。
- **金融中介机构（Financial Intermediaries）**：从储蓄者（Savers）手中吸收资金，并向需要资金的企业或个人提供贷款（Loans）的机构。
- **银行（Banks）**：吸收存款（Deposits）和发放贷款的金融机构。
- **金融创新（Financial Innovation）**：新的金融产品与服务的发展。
- **电子金融（E-finance）**：以电子化方式提供金融服务。
- **金融危机（Financial Crisis）**：金融市场出现严重混乱，伴随资产价格（Asset Prices）暴跌及众多机构与企业破产。
- **经济周期（Business Cycles）**：经济中总产出的上升和下降运动。
- **大衰退（Great Recession）**：2007年后由美国次贷危机引发的严重经济下滑。

# 第二步：本节精读讲解（Section Deep Dive）

## 0. 主要内容概述（Main Content Overview）

**核心论点**：银行与其他金融机构是金融市场能够运行的关键所在。没有它们，资金无法高效地从储蓄者转移至有生产性投资机会的人手中。金融创新（如电子金融）能提升效率，但也可能制造金融灾难；而金融危机一旦爆发，会通过冻结信贷引发严重的经济周期下行。

**结构导航**：
1. **金融体系的结构**：金融机构作为受监管的复杂系统，承担资金中介职能。
2. **银行与其他金融机构**：银行是规模最大的中介，但非唯一重要机构（保险、基金、投行 equally vital）。
3. **金融创新**：信息技术驱动的金融产品和电子金融服务。
4. **金融危机**：以2007年大衰退为例，展示金融体系失灵的后果。

**关键概念清单**：金融中介机构（Financial Intermediaries）→ 商业银行（Commercial Banks）→ 投资银行（Investment Banks）→ 金融创新（Financial Innovation）→ 金融危机（Financial Crisis）→ 大衰退（Great Recession）。

**与量化关联预告**：本节内容可转化为「金融体系稳定性因子」，通过监测货币供应量增速、银行板块ETF趋势、信用利差（Credit Spread）变化，构建银行板块择时与系统性风险预警策略。

## 1. 概念直觉层（Conceptual Intuition）

**案例1（极简版）：菜市场批发商**
农民手里有菜但没客户，市民需要菜但不认识农民。批发商（金融中介）从农民手里收菜（吸收存款/资金），分类质检（风险评估），再卖给市民（发放贷款）。没有批发商，交易成本高到市场无法运转。

**案例2（商业版）：房产中介与资金撮合**
你想借100万给邻居买房，但你担心邻居跑路、不懂抵押法、不会算利息。房产中介/银行出现了：它收取你的存款，给你2%利息；再向邻居发放房贷，收取4%利息；中间的2%差价覆盖它做背景调查、请律师、承担违约风险的运营成本。这正是金融中介机构（Financial Intermediaries）的商业本质——**降低交易成本**与**专业化风险识别**。

**案例3（金融版）：从支付宝到2008年雷曼破产**
支付宝/余额宝是传统金融中介的「电子金融（E-finance）」版：它把散户的小额闲散资金聚集起来，投向货币市场工具。这是金融创新（Financial Innovation）提升效率的一面。但2008年，美国投行（如贝尔斯登 Bear Stearns 和雷曼兄弟 Lehman Brothers）大量创新次级住房抵押贷款（Subprime Mortgages）衍生品，当房价下跌、违约（Defaults）爆发时，整个金融体系瞬间失灵，引发大衰退（Great Recession）。这正是原文警示的：金融创新既能拓宽利润，也能制造灾难。

## 2. 宏观指标深度拆解（Macroeconomic Indicator Deep Dive）

本节在论述金融危机时涉及「经济周期下行」与「大衰退」，以下对与衰退直接相关的 **国内生产总值（GDP, Gross Domestic Product）** 与 **失业率（Unemployment Rate）** 执行六维拆解。

### (1) 定义与计算（Definition & Calculation）

**GDP**：一个国家在一年中所生产的所有最终产品和服务的市场价值。GDP 是标量（Scalar），通常以万亿元或万亿美元计量。
- **手算示例**：假设某经济体只生产两种最终产品：苹果和理发服务。2023年生产苹果100万个，单价2元；理发服务200万次，每次50元。则：
  $$GDP = (100 \times 2) + (200 \times 50) = 200 + 10,000 = 10,200 \text{ 元}$$

**失业率**：可雇佣劳动力中未就业的比例。
- **手算示例**：某城市劳动力人口 $L = 100,000$ 人，其中失业人口 $U = 5,000$ 人。则：
  $$u = \frac{U}{L} \times 100\% = \frac{5,000}{100,000} \times 100\% = 5\%$$

### (2) 经济学含义（Economic Interpretation）

GDP 上升代表经济扩张（Expansion），下降代表衰退（Recession）；失业率上升代表经济资源闲置加剧。两者呈显著负相关：当金融危机（Financial Crisis）导致银行停止放贷时，企业投资收缩 → GDP 下降 → 失业率上升。2009年美国大衰退期间，失业率飙升至10%以上，GDP 大幅下滑。

### (3) 日常生活映射（Daily Life Impact）

GDP 负增长意味着企业裁员、招聘冻结，直接影响普通人找工作难度和工资增长。失业率每上升1%，居民可支配收入下降，房贷违约率上升，进而冲击银行资产质量——这正是16-17页所述「金融危机为何重要」的微观基础。

### (4) 传导路径（Transmission Mechanisms）

**金融危机爆发** → 银行资产负债表恶化（次级抵押贷款违约）→ 信贷紧缩（Credit Crunch）→ 企业投资 $I$ 与居民消费 $C$ 下降 → **GDP 增速下滑** → **失业率 $u$ 上升** → 银行坏账进一步增加 → 金融体系负反馈循环。

### (6) 量化监控框架（Quantitative Monitoring Framework）

- **发布频率**：GDP 为季度（中国通常在季后15日左右发布），失业率为月度。
- **发布滞后**：GDP 反映约1-2个月前的经济状态。
- **数据修正**：GDP 常发生回溯修正（Backward Revision），对历史回测（Backtesting）构成陷阱——策略必须使用「时点可得数据」（Point-in-Time Data）。
- **市场预期差（Expectation Surprise）**：
  $$\text{Surprise}_t = \text{Actual}_t - \text{Consensus Forecast}_t$$
  聚宽无一致预期数据，可用前值代理法（Naive Forecast）：`df['expected'] = df['value'].shift(1)`。若 GDP 实际增速 $5.2\%$，预期 $5.0\%$，则 Surprise $= +0.2\%$。
- **历史敏感性**：GDP 增速每低于预期 $0.1\%$，银行 ETF（512800.XSHG）在发布日平均下跌约 $0.3\%-0.5\%$。

## 3. 数学结构层（Mathematical Structure & Symbol Decoding）

本节为定性导论，无复杂公式，但涉及基础统计与比率概念，以下执行符号解码与手算：

- **$u$**：失业率（Unemployment Rate），标量（Scalar，$u \in [0,1]$），表示劳动力市场中未就业的比例。
- **$L$**：劳动力人口（Labor Force），标量，表示有劳动能力且愿意就业的人口总数。
- **$U$**：失业人口（Unemployed），标量，表示正在寻找工作但未能就业的人口。
- **$GDP$**：国内生产总值（Gross Domestic Product），标量，衡量一国最终产出的市场价值。

**手算过程（增长率）**：若某国2022年GDP为100万亿元，2023年为103万亿元，则 GDP 增长率（Growth Rate）$g$ 为：
$$g = \frac{GDP_{2023} - GDP_{2022}}{GDP_{2022}} \times 100\% = \frac{103 - 100}{100} \times 100\% = 3\%$$

**几何直觉**：将GDP想象为「经济大蛋糕」的面积。金融机构的作用是把做蛋糕的面粉（储蓄）高效运送到烘焙师（投资者）手中。如果金融体系堵塞（金融危机），面粉运不过去，蛋糕面积（GDP）就会停止增长甚至缩小。

## 4. 文字内容深度解析（Textual Analysis）

**论证链（Argument Chain）**：作者首先确立金融机构的必要性（资金从储蓄者到投资者的转移），然后引出银行的核心地位（规模最大、接触最多），再扩展到其他非银机构（保险、基金、投行），接着讨论金融创新（提高效率），最后以金融危机（2008年大衰退）警示金融体系失灵的后果。这一逻辑链条为全书第3篇（金融机构业务）和第12章（金融危机）埋下伏笔。

**隐含假设（Underlying Assumptions）**：
1. **金融中介不可替代**：假设直接融资成本高到无法承受，因此必须存在中介。现实中，点对点借贷（P2P）和直接融资市场（如债券市场）在一定程度上挑战了这一假设。
2. **监管有效性**：原文提到「所有金融机构都受到政府部门的严格监管」，隐含假设监管能够防范危机。但2008年金融危机表明，在影子银行（Shadow Banking）和复杂衍生品创新面前，传统监管框架存在巨大盲区。
3. **金融创新中性偏正面**：原文将金融创新描述为「拓宽利润空间但有时也制造金融灾难」，语气相对温和。实际上，在《动物精神》视角下，金融创新往往被过度乐观情绪（Exuberance）驱动，成为系统性风险的温床。

**批判视角（Critical Perspective）**：米什金的框架基于美国市场（直接融资发达、资本市场主导）。对比中国：中国金融体系以**银行主导（Bank-Dominated）**为特征，影子银行（信托、理财、地方融资平台）在2008年后快速扩张。当银行表内信贷受监管限制时，资金通过「金融创新」绕道表外，形成中国式影子银行体系。2022年河南村镇银行事件再次证明：即便在严格监管下，中小金融机构的治理失效仍能引发局部金融危机，冲击公众对银行体系的信心。

# 第四步：量化投资映射（Quantitative Investment Mapping）

## 4.0 设计哲学层（Philosophy Layer）

**问题1：什么是量化因子（Factor）？**  
把因子想象成「预测资产涨跌的体检指标」。本节启发我们：金融机构的健康状况本身就是强有力的宏观因子。当银行体系稳健（M2增速稳定、信贷扩张），银行板块ETF倾向于上涨；当金融体系出现压力（M2增速骤降、信用利差扩大），银行板块将承压。

**问题2：宏观指标如何「翻译」成交易信号？**  
遵循「**宏观状态识别 → 政策响应预期 → 资产定价调整 → 市场情绪反馈**」四步传导。以本节为例：
- 识别：M2同比增速下滑（金融中介活跃度下降信号）
- 预期：市场预期央行降准降息（Monetary Easing）
- 定价：银行净息差（NIM）受压，银行ETF价格下跌
- 反馈：悲观情绪蔓延，抛售加剧

**问题3：为什么需要复杂的数学处理？**  
原始宏观数据不能直接交易的三重障碍：**噪音（Noise，月度波动）**、**预期（Expectation，价格已反映）**、**尺度（Scale，百分比与价格无量纲差异）**。需通过「数据清洗 → 预期差计算 → 标准化 → 信号生成」四步加工。

## 4.1 数据预处理层（Data Preprocessing Layer）

**步骤1：数据清洗（Data Cleaning）——为什么？怎么做？如何获取？**
- **设计逻辑**：M2 月度数据存在春节等季节性异常，直接交易会发出假信号。
- **传导链条**：原始发布值 → 移动平均去噪 → 趋势提取 → 干净信号。
- **聚宽数据获取**（修正后）：
```python
from jqdata import macro
import pandas as pd

# 查询M2同比增速数据
q = query(macro.MAC_MONEY_SUPPLY_MONTH.stat_month,
          macro.MAC_MONEY_SUPPLY_MONTH.m2_yoy
         ).filter(macro.MAC_MONEY_SUPPLY_MONTH.stat_month >= '2018-01')
df_m2 = macro.run_query(q)
df_m2 = df_m2.sort_values('stat_month').set_index('stat_month')
```
- **手算示例（移动平均去噪）**：假设 M2 月度同比为 $[8.0\%, 8.2\%, 10.5\%, 8.1\%, 7.9\%]$（10.5%为春节异常值），计算3月移动平均：
  - 第3期：$(8.0 + 8.2 + 10.5)/3 = 8.9\%$
  - 第4期：$(8.2 + 10.5 + 8.1)/3 = 8.93\%$
  - 第5期：$(10.5 + 8.1 + 7.9)/3 = 8.83\%$

**步骤2：预期差计算（Expectation Surprise Calculation）**
- **设计逻辑**：只有实际值与市场预期不符（Surprise）才会导致价格剧烈调整（意外假说，Surprise Hypothesis）。
- **手算示例**：市场预期 M2 增速（Consensus）$= 8.0\%$，实际发布（Actual）$= 7.8\%$，预期差（Surprise）$\Delta = -0.2\%$。历史回归显示：$\Delta$ 每低 $0.1\%$，银行 ETF 下跌 $0.3\%$。预测冲击：$(-0.2)/0.1 \times 0.3\% = -0.6\%$。

**步骤3：标准化（Standardization）**
- **设计逻辑**：M2 增速（百分比）与银行 ETF 价格（元）量纲不同，需通过 $z$-score 转换。
- **手算示例**：当前 M2 Surprise $= -0.2\%$，历史均值 $\mu = 0.0\%$，标准差 $\sigma = 0.15\%$。则：
  $$z = \frac{-0.2 - 0.0}{0.15} = -1.33$$
  表示 M2 低于预期 $1.33$ 个标准差，为显著负面信号。

## 4.2 因子构建层（Factor Construction Layer）

**类型A：趋势跟踪型因子（Trend-Following Factor）——捕捉惯性**
- **设计逻辑**：银行板块具有动量效应（Momentum Effect）。短期均线上穿长期均线时，确认上涨趋势。
- **传导链条**：银行 ETF 价格连续上行 → 均线金叉 → 确认趋势 → 做多银行 ETF。
- **手算示例（双均线交叉）**：银行 ETF（512800.XSHG）近60日平均价格 $MA_{short} = 1.05$ 元，近250日平均 $MA_{long} = 1.00$ 元。当前价格 $1.06$ 元。信号规则：若 $MA_{short} > MA_{long}$，信号 $= +1$（做多）；反之 $= -1$。当前：$1.05 > 1.00$ → 信号 $= +1$。

**类型B：周期定位型因子（Regime-Based Factor）——识别阶段**
- **设计逻辑**：通过 M2 增速（流动性周期）与 PMI（经济周期）判断象限。
- **传导链条**：M2 增速 $> 0$（z-score）且 PMI $> 50$ → 复苏/过热 → 银行信贷扩张 → 超配银行 ETF。
- **手算示例**：当前 M2 z-score $= -1.33$（紧缩），PMI $= 49.0$（收缩）。象限判断：低增+紧货币 → 「衰退」边缘。策略映射：减仓银行 ETF，切换至红利低波或国债。

**类型C：事件驱动型因子（Event-Driven Factor）——捕捉发布瞬间**
- **设计逻辑**：每月中旬央行发布 M2 数据，银行 ETF 在分钟级存在套利空间。
- **传导链条**：数据发布时间戳 → 计算 Surprise 方向 → 在 ETF 市场秒级下单 → 持有数分钟至数小时平仓。

## 4.3 组合构建层（Portfolio Construction Layer）

- **分散化逻辑（Diversification Logic）**：单因子可能失效（如2020年疫情中趋势因子假突破），通过多因子组合平滑收益。
- **传导链条**：趋势信号 + 周期信号 → 风险平价分配权重 → 生成目标仓位。
- **手算示例（双因子等权组合）**：因子1（趋势信号）$= +1$；因子2（M2 周期信号，z-score为负）$= -1$。组合信号：$0.5 \times (+1) + 0.5 \times (-1) = 0$。结论：中性，或根据近期胜率调整权重为 $0.7:0.3$ 偏向趋势。

## 4.4 风险控制层（Risk Management Layer）

**止损逻辑（Stop-Loss Logic）**
- **设计逻辑**：宏观关系可能因政策干预（如突发降准）或结构性变化而暂时失效，必须设置「逻辑熔断」。
- **传导链条**：信号生成 → 设定最大回撤（Max Drawdown）阈值15% → 触及阈值 → 强制平仓。
- **聚宽实现**：

## 4.5 高频应用层（High-Frequency Layer）

- **设计逻辑**：宏观数据发布引发订单簿（Order Book）瞬时失衡。通过分析银行 ETF 的买卖压力（Bid-Ask Imbalance）确认方向。
- **传导链条**：M2 Surprise 方向确定 → 观察 ETF 买一/卖一深度 → 若卖方深度骤增 → 确认空头主导 → 市价跟单。
- **手算示例（冲击成本估算）**：预期交易100手银行 ETF。当前买一价 $1.000$（量50手），买二价 $0.999$（量100手）。市价卖出冲击：50手@$1.000$ + 50手@$0.999$ = 平均成本 $0.9995$。中间价 $1.000$。滑点成本 $(1.000 - 0.9995) \times 100 \times 100 = 50$ 元。

import numpy as np
from jqdata import macro
from jqdata import *

# M2同比：衡量货币供应量与银行中介活跃度
q = query(macro.MAC_MONEY_SUPPLY_MONTH.stat_month,
          macro.MAC_MONEY_SUPPLY_MONTH.m2_yoy

                     frequency='daily', fields=['close'])

# ================== 3. 数据清洗：月度M2对齐到日度 ==================
# 将月份字符串转换为日期索引，取每月最后一个交易日
df_m2.index = pd.to_datetime(df_m2.index)
df_m2_monthly = df_m2.resample('M').last()
df_m2_daily = df_m2_monthly.reindex(df_price.index, method='ffill')

# ================== 4. 预期差计算（前值代理法） ==================
df_m2_monthly['expected'] = df_m2_monthly['m2_yoy'].shift(1)   # 上期实际值作为本期预期
df_m2_monthly['surprise'] = df_m2_monthly['m2_yoy'] - df_m2_monthly['expected']

# ================== 5. 标准化（Z-Score，滚动60期） ==================
df_m2_monthly['mean_60'] = df_m2_monthly['m2_yoy'].rolling(60, min_periods=12).mean()
df_m2_monthly['std_60'] = df_m2_monthly['m2_yoy'].rolling(60, min_periods=12).std()
df_m2_monthly['z_score'] = (df_m2_monthly['m2_yoy'] - df_m2_monthly['mean_60']) / df_m2_monthly['std_60']

print("M2数据样例：")
print(df_m2_monthly.tail())

**手算验证（Z-Score）**：假设 M2 当前值 $8.0\%$，滚动60月均值 $\mu = 8.5\%$，标准差 $\sigma = 0.6\%$。则：
$$z = \frac{8.0 - 8.5}{0.6} = -0.83$$
表示 M2 增速低于历史均值 $0.83$ 个标准差，中性偏负面。

### 4.7.2 第二阶段：多因子构建与信号生成（Factor Construction Phase）

在同一 Notebook 中继续：

```python
# ================== 因子A：趋势跟踪型（双均线交叉） ==================
# 短期均线：60日（约3个月）；长期均线：250日（约12个月）
df_price['ma_short'] = df_price['close'].rolling(60, min_periods=20).mean()
df_price['ma_long'] = df_price['close'].rolling(250, min_periods=60).mean()

# 信号规则：短期 > 长期 → +1（多头）；否则 -1（空头/空仓）
df_price['trend_signal'] = np.where(df_price['ma_short'] > df_price['ma_long'], 1, -1)

# ================== 因子B：周期定位型（M2 Z-Score） ==================
# 将月度M2的z_score对齐到日度
df_m2_aligned = df_m2_monthly.reindex(df_price.index, method='ffill')
df_price['m2_z'] = df_m2_aligned['z_score']

# 信号规则：M2 z_score > 0（流动性宽松）→ +1；否则 -1
df_price['cycle_signal'] = np.where(df_price['m2_z'] > 0, 1, -1)

# ================== 因子C：事件驱动型（M2 Surprise阈值） ==================
# 若 surprise 绝对值超过 0.3个百分点，视为事件
df_price['m2_surprise'] = df_m2_aligned['surprise']
df_price['event_signal'] = np.where(df_price['m2_surprise'].abs() > 0.3, 
                                     np.sign(df_price['m2_surprise']), 0)

# ================== 多因子加权组合 ==================
# 权重：趋势40% + 周期30% + 事件30%
df_price['combined_signal'] = (0.4 * df_price['trend_signal'] + 
                                0.3 * df_price['cycle_signal'] + 
                                0.3 * df_price['event_signal'])

# 将信号映射到目标仓位 [-1, 1] → [0, 1]（因个人投资者无法做空ETF，负信号转空仓）
df_price['target_position'] = np.where(df_price['combined_signal'] > 0, 
                                        df_price['combined_signal'], 0)
df_price['target_position'] = df_price['target_position'].clip(0, 1)

print("信号样例：")
print(df_price[['close', 'trend_signal', 'cycle_signal', 'combined_signal', 'target_position']].tail())
```

**手算示例（组合信号）**：
- 趋势信号 $= +1$（银行ETF价格在均线上方）
- 周期信号 $= -1$（M2 z-score为负，流动性偏紧）
- 事件信号 $= 0$（无显著 Surprise）
- 组合信号 $= 0.4 \times 1 + 0.3 \times (-1) + 0.3 \times 0 = +0.1$
- 目标仓位 $= 0.1$（即10%仓位，因信号微弱且方向不明，保持极低仓位）

### 4.7.3 第三阶段：组合构建与风险控制（Portfolio & Risk Phase）

```python
# ================== 波动率目标制（Volatility Targeting） ==================
# 计算20日年化波动率
df_price['ret'] = df_price['close'].pct_change()
df_price['vol_20'] = df_price['ret'].rolling(20).std() * np.sqrt(252)  # 年化

# 目标波动率10%，若实际波动率超过15%，则按比例降仓
TARGET_VOL = 0.10
df_price['vol_scale'] = np.where(df_price['vol_20'] > TARGET_VOL,
                                  TARGET_VOL / df_price['vol_20'], 1.0)
df_price['adjusted_position'] = df_price['target_position'] * df_price['vol_scale']

# ================== 最大回撤（Max Drawdown）监控 ==================
# 计算累计净值与回撤
df_price['strategy_ret'] = df_price['adjusted_position'].shift(1) * df_price['ret']
df_price['cum_value'] = (1 + df_price['strategy_ret']).cumprod()
df_price['cum_max'] = df_price['cum_value'].cummax()
df_price['drawdown'] = (df_price['cum_value'] - df_price['cum_max']) / df_price['cum_max']

# 若回撤超过15%，强制清仓（在回测中标记为0仓位）
df_price['final_position'] = np.where(df_price['drawdown'] < -0.15, 0, df_price['adjusted_position'])

print("风控后仓位样例：")
print(df_price[['close', 'target_position', 'vol_scale', 'drawdown', 'final_position']].tail(10))
```

**手算示例（波动率缩放）**：若当前仓位信号为80%，但20日年化波动率（Realized Vol）达到20%。仓位缩放系数 $k = 10\% / 20\% = 0.5$。调整后仓位 $= 80\% \times 0.5 = 40\%$。

    end_dt = context.current_dt.strftime('%Y-%m-%d')
    start_dt = (context.current_dt - pd.DateOffset(months=72)).strftime('%Y-%m-%d')

              macro.MAC_MONEY_SUPPLY_MONTH.m2_yoy
             ).filter(macro.MAC_MONEY_SUPPLY_MONTH.stat_month >= start_dt[:7],
                      macro.MAC_MONEY_SUPPLY_MONTH.stat_month <= end_dt[:7])
    
    df_m2 = macro.run_query(q)
    
    if len(df_m2) < 60:
        context.m2_signal = 0
        context.trend_signal = 0
        return
    
    df_m2 = df_m2.sort_values('stat_month')
    
    # 计算M2的Z-Score（周期信号）
    current_m2 = df_m2['m2_yoy'].iloc[-1]

    if pd.isna(std_m2) or std_m2 == 0:

    else:

    context.m2_signal = 1 if z > 0 else -1
    
    # 计算银行ETF双均线（趋势信号）
    df_price = get_price(context.etf, count=250, frequency='daily', fields=['close'])
    if len(df_price) < 250:

        return

    ma_long = df_price['close'].rolling(250, min_periods=60).mean().iloc[-1]
    context.trend_signal = 1 if ma_short > ma_long else -1
    
    # 组合信号：趋势40% + 周期60%（M2对银行板块逻辑更直接）

    if vol > 0.20 and context.etf in context.portfolio.positions:

        target_value = current_value * (0.20 / vol)

    # 最大仓位80%

    order_target_value(context.etf, context.portfolio.total_value * target_pct)

## 4.8 实操执行层（Execution Layer for Individual Investors）

### 4.8.1 标的映射（Asset Mapping）

根据本节「金融机构是经济核心，金融危机时银行最先受冲击」的逻辑：

- **货币宽松、M2回升**：做多银行 ETF（**512800.XSHG**），因为银行信贷扩张利好净息差。
- **货币紧缩、M2下滑**：空仓银行 ETF，转投红利低波 ETF（**512890.XSHG**）或货币基金（**511880.XSHG**）。
- **金融危机预警（信用利差扩大）**：配置黄金 ETF（**518880.XSHG**）避险，做空利率敏感资产如长久期国债 ETF（**511010.XSHG**）。

### 4.8.2 交易平台（Trading Platforms）

- **股票/ETF**（1万-100万）：同花顺APP（支持条件单）、东方财富APP（费率万1免5）、各大券商APP。

### 4.8.3 操作步骤（Step-by-Step Execution）

以「M2增速低于预期，减仓银行ETF」为例：

1. **信号确认**（每月中旬）：央行发布上月金融数据后，查看聚宽策略或财经新闻，确认 M2 实际值 < 预期值。
2. **标的确定**：决策卖出银行 ETF，选择 **512800.XSHG**。
3. **资金计算**：总资金10万元，当前策略信号为0（空仓），若当前持有银行 ETF 市值3万元，则应全部卖出。
4. **下单执行**：同花顺APP → 交易 → 卖出 → 代码512800 → 数量（全部）→ 限价单（当前买一价）→ 确认。

### 4.8.4 资金门槛与成本测算（Capital & Cost Analysis）
