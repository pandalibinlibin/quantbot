全球数字货币交易所

接口：coinexchanges
描述：获取全球数字货币交易所基本信息。

输入参数

名称 类型 必选 描述
exchange str N 交易所
area_code str N 地区 （见下面列表）

输出参数

名称 类型 描述
exchange str 交易所代码
name str 交易所名称
pairs int 交易对数量
area_code str 所在地区代码
area str 所在地区
coin_trade str 支持现货交易
fut_trade str 支持期货交易
oct_trade str 支持场外交易
deep_share str 支持共享交易深度
mineable str 支持挖矿交易
desc str 交易所简介
website str 交易所官网
twitter str 交易所twitter
facebook str 交易所facebook
weibo str 交易所weibo

接口用法


pro = ts.pro_api()

df = pro.coinexchanges(area_code='us')

#按交易对数量排序
df = df.sort('pairs', ascending=False)

或者 


df = pro.query('coinexchanges', area_code='us')
